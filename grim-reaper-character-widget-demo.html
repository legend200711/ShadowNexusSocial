Floating Character Widget  ·  Zero Dependencies  ·  One Script Tag

The animated Grim Reaper character appears as a floating presence on any page of your website — fully visible, uncropped, and animated. No chat window. No buttons attached. Just the character.

Look towards the top-right corner of this page.

Integration — One Line

Place the script tag anywhere in your page — ideally in a shared layout template so GRIM appears on every page automatically.

<!-- Drop this once into any page or shared layout --> <script src="grim-reaper-character-widget.js"></script>

GRIM loads lazily after the page is interactive — it never blocks rendering.

Optional Configuration

Set window.GrimCharConfig before the script tag to customise position, size, and screen offset:

<script> window.GrimCharConfig = { position : 'top-right', // 'top-right' | 'top-left' | 'bottom-right' | 'bottom-left' size : 'auto', // 'auto' (responsive) | 'small' | 'medium' | 'large' offsetX : 0, // pixels nudge from corner (horizontal) offsetY : 0 // pixels nudge from corner (vertical) }; </script> <script src="grim-reaper-character-widget.js"></script>

JavaScript API

Control the widget at runtime from anywhere on your site:

// Change position GrimChar.setPosition('bottom-left'); GrimChar.setPosition('top-right'); // Change size GrimChar.setSize('small'); GrimChar.setSize('medium'); GrimChar.setSize('large'); // Fine-tune position offset (pixels from corner) GrimChar.setOffset(20, 40);

Technical Notes

The widget is a single JavaScript file — no external CSS, no images, no fonts. All artwork is drawn procedurally using the Canvas 2D API.

It uses requestIdleCallback (or setTimeout 0 fallback) to defer initialisation until the browser is idle, so it never competes with your page's critical rendering path.

The widget container has pointer-events: none, so it is purely decorative and does not interfere with any clickable elements on your page.

On resize, the character automatically recalculates its stage dimensions and clamps to at most 90% of the shorter viewport dimension to stay fully visible on any screen.
